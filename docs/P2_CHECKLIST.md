# P2 completion tracker

This tracker follows John Guerra's CS 6983 handout [Building P2 from Zero — Checklist](https://github.com/john-guerra/ai-coding-class/blob/main/course/handouts/p2-from-zero-checklist.md) (version `86523f4`) and the additional requirements and rubric in the [P2 specification](https://github.com/john-guerra/ai-coding-class/blob/main/course/projects/project2-full-stack.md) (version `c6a67a1`, which moved the due date to Thursday, November 12, 2026, 11:59 PM PT). The item wording is condensed from those documents.

The two sources carry different weight. Steps 0–7 come from the companion checklist, which says it "is not the rubric": its items are recommended practice, such as `DESIGN.md`, a seed script, a health check, branch protection, and a pre-commit hook. The sections under "What P2 also requires" follow the P2 specification and its 200-point rubric, and they are the graded requirements.

**Last checked: 2026-11-09** by Chengling against the repository, the GitHub API (issues, board, pull requests, reviews, commits, Actions runs, deployments, and repository settings), anonymous requests to the Vercel URLs, and local command runs. Vercel facts come from the Vercel dashboard and API, signed in as the project owner on 2026-11-09. Update a row in the same pull request that changes its status, and mark something Done only after checking the actual files, results, or links.

Statuses:

| Status | Meaning |
| --- | --- |
| Done | Merged to `main`, or recorded on GitHub, and verified |
| Awaiting merge | Implemented and verified in an open pull request that still needs partner review |
| Partial | Some of the item is done; the remaining action says what is left |
| Pending verification | Reported done, but the evidence is not yet linked or checked |
| Not started | No work yet |
| Optional | Not required for P2 |
